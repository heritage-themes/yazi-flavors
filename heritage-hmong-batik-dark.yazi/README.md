# Hmong Batik (Dark) for yazi

Hmong Batik (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Hmong family: The batik and cross-stitch of the Hmong pleated skirt: names in the tones of indigo batik, with pink keywords, lime strings and orange numbers from the cross-stitch, on indigo or undyed hemp. Its colours are those of the Hmong Batik (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-hmong-batik-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/hmong) describes its colour tradition.
