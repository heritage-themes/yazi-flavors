# Mughal Night for yazi

Mughal Night is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Mughal family: Mughal miniature painting: lapis-lazuli keywords, vermilion types, gold-leaf methods and verdigris strings on a lamp-lit night or burnished wasli paper, with Spock labels lettered in gold. Its colours are those of the Mughal Night theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-mughal-night"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/mughal) describes its colour tradition.
