# Złotnica Aksamit (Dark) for yazi

Złotnica Aksamit (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Złotnica family: The gold-and-silver embroidered bonnets of Kashubia: hierarchy by metal, tone and weight, with sapphire, burgundy and emerald velvet as the only colours, on green velvet or white linen. Its colours are those of the Złotnica Aksamit (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-zlotnica-aksamit-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/zlotnica) describes its colour tradition.
