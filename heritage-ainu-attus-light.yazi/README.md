# Ainu Attus (Light) for yazi

Ainu Attus (Light) is a light flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Ainu family: The appliqué robes of the Ainu of Hokkaido: bold appliqué keywords, red method declarations at the openings, green thread strings, yellow fields and blue-violet numbers, on indigo cotton or elm-bark cloth. Its colours are those of the Ainu Attus (Light) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
light = "heritage-ainu-attus-light"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/ainu) describes its colour tradition.
