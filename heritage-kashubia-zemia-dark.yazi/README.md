# Kashubia Zemia (Dark) for yazi

Kashubia Zemia (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Kashubia family: The seven colours of Kashubian embroidery: cornflower keywords, navy types and light-blue methods under yellow strings, green fields and red numbers, on black earth or white linen. Its colours are those of the Kashubia Zemia (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-kashubia-zemia-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/kashubia) describes its colour tradition.
