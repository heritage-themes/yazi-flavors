# Bengal Baluchari (Dark) for yazi

Bengal Baluchari (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Bengal family: Bengal's looms and Durga Puja: aparajita keywords, Baluchari-magenta strings, paddy-green methods and terracotta types, on wine-dark Baluchari silk or a white laal paar sari with a red border. Its colours are those of the Bengal Baluchari (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-bengal-baluchari-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/bengal) describes its colour tradition.
