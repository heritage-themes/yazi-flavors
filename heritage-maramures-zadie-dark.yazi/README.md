# Maramureș Zadie (Dark) for yazi

Maramureș Zadie (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Maramureș family: The striped aprons and flowered skirts of Maramureș, coloured by age: married red keywords, pumpkin-flower strings, blue numbers, dark green types, rose methods and leather-brown fields. Its colours are those of the Maramureș Zadie (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-maramures-zadie-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/maramures) describes its colour tradition.
