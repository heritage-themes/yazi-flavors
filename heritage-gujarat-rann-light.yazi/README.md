# Gujarat Rann (Light) for yazi

Gujarat Rann (Light) is a light flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Gujarat family: Gujarat's Navratri, Rann of Kutch and patola silk: parrot-green keywords, patola-red types, turmeric methods and garba-pink strings, on a mirror-worked night or the white salt desert. Its colours are those of the Gujarat Rann (Light) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
light = "heritage-gujarat-rann-light"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/gujarat) describes its colour tradition.
