# Łowicz Kodra (Light) for yazi

Łowicz Kodra (Light) is a light flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Łowicz family: The striped wool and layered paper cut-outs of Łowicz: orange keywords, green strings, emerald types and violet methods with yellow fields and cinnabar numbers, on a black template or a white paper strip. Its colours are those of the Łowicz Kodra (Light) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
light = "heritage-lowicz-kodra-light"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/lowicz) describes its colour tradition.
