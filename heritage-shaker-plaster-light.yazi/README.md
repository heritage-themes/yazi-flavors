# Shaker Plaster (Light) for yazi

Shaker Plaster (Light) is a light flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Shaker family: The paint of the Shaker villages: bold meetinghouse keywords in plaster white or Prussian blue, Shaker red strings, pumpkin methods, yellow ochre fields, chrome green types and verdigris numbers. Its colours are those of the Shaker Plaster (Light) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
light = "heritage-shaker-plaster-light"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/shaker) describes its colour tradition.
