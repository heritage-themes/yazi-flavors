# Peru Puka (Dark) for yazi

Peru Puka (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Peru family: Andean natural dyes on two dyed-through grounds: q'olle-yellow keywords, ch'illka-green strings and anqas-blue types on purple corn, and ch'illka-green keywords with turquoise methods on cochineal crimson. Its colours are those of the Peru Puka (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-peru-puka-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/peru) describes its colour tradition.
