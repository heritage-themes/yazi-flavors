# Mudhif Qasab (Light) for yazi

Mudhif Qasab (Light) is a light flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Mudhif family: The reed guest house of the Marsh Arabs of Iraq: hierarchy from the tone and weight of reed gold, with green reed shoots for strings and the willow fire for numbers. Its colours are those of the Mudhif Qasab (Light) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
light = "heritage-mudhif-qasab-light"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/mudhif) describes its colour tradition.
