# Zalipie Wapno (Light) for yazi

Zalipie Wapno (Light) is a light flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Zalipie family: The painted cottages of Zalipie: lime, soot and clay for text, keywords and comments, and the flowers for names, with rose methods, leaf-green strings and violet types, on a soot plinth or a lime-washed wall. Its colours are those of the Zalipie Wapno (Light) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
light = "heritage-zalipie-wapno-light"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/zalipie) describes its colour tradition.
