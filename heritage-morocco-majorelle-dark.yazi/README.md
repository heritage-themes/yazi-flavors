# Morocco Majorelle (Dark) for yazi

Morocco Majorelle (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Morocco family: Three Moroccan walls on saturated backgrounds: Majorelle ultramarine with yellow pots, Marrakech red clay with turquoise doors, and zellige jade with saffron and cobalt tile. Its colours are those of the Morocco Majorelle (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-morocco-majorelle-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/morocco) describes its colour tradition.
