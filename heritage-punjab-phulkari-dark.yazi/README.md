# Punjab Phulkari (Dark) for yazi

Punjab Phulkari (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Punjab family: Punjab's phulkari embroidery and Basant mustard fields: golden-silk keywords, orange-silk methods, turquoise strings and saag-green types, on madder-rust khaddar or a field of flowering mustard. Its colours are those of the Punjab Phulkari (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-punjab-phulkari-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/punjab) describes its colour tradition.
