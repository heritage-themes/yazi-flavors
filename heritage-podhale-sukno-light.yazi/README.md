# Podhale Sukno (Light) for yazi

Podhale Sukno (Light) is a light flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Podhale family: The Highlander costume of Podhale: crimson keywords and navy strings from the cords of the parzenica, brass methods, green fields, blue types and coral numbers, on a black felt hat or white broadcloth. Its colours are those of the Podhale Sukno (Light) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
light = "heritage-podhale-sukno-light"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/podhale) describes its colour tradition.
