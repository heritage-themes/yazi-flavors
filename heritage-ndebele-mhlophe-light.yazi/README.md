# Ndebele Mhlophe (Light) for yazi

Ndebele Mhlophe (Light) is a light flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Ndebele family: The painted walls of the Ndebele homestead: keywords drawn as the black outline, with sky-blue types, green methods, yellow strings and pink fields as the flat fills, on black paint or white lime-wash. Its colours are those of the Ndebele Mhlophe (Light) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
light = "heritage-ndebele-mhlophe-light"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/ndebele) describes its colour tradition.
