# Maya Corte (Dark) for yazi

Maya Corte (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Maya family: The town dress of the Guatemalan Maya read through the K'iche' colour roads: green keywords, red strings, yellow types, purple methods and indigo fields, on the jaspe corte or the white huipil. Its colours are those of the Maya Corte (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-maya-corte-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/maya) describes its colour tradition.
