# Yolŋu Galawu (Dark) for yazi

Yolŋu Galawu (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Yolŋu family: The ochres of Yolŋu bark painting from north-east Arnhem Land: red keywords, yellow strings, orange types, haematite fields and pink numbers, with white or charcoal methods, on stringybark or white clay. Its colours are those of the Yolŋu Galawu (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-yolngu-galawu-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/yolngu) describes its colour tradition.
