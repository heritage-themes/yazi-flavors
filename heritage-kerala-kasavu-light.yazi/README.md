# Kerala Kasavu (Light) for yazi

Kerala Kasavu (Light) is a light flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Kerala family: Kerala's backwaters, Kathakali stage and kasavu loom: kathi-red keywords, zari-gold strings, pacha-green methods and backwater-teal types, on palm-dark water at night or off-white handloom with a gold border. Its colours are those of the Kerala Kasavu (Light) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
light = "heritage-kerala-kasavu-light"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/kerala) describes its colour tradition.
