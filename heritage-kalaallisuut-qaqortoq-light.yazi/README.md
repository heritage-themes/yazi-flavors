# Kalaallisuut Qaqortoq (Light) for yazi

Kalaallisuut Qaqortoq (Light) is a light flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Kalaallisuut family: The West Greenlandic national dress and its colours for age and marital status: red keywords, confirmation pink strings, yellow kamik numbers, blue anorak types, green bead methods and black-and-white fields. Its colours are those of the Kalaallisuut Qaqortoq (Light) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
light = "heritage-kalaallisuut-qaqortoq-light"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/kalaallisuut) describes its colour tradition.
