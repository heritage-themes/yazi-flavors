# Kerala Backwaters (Dark) for yazi

Kerala Backwaters (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Kerala family: Kerala's backwaters, Kathakali stage and kasavu loom: kathi-red keywords, zari-gold strings, pacha-green methods and backwater-teal types, on palm-dark water at night or off-white handloom with a gold border. Its colours are those of the Kerala Backwaters (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-kerala-backwaters-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/kerala) describes its colour tradition.
