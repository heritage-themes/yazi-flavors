# Holi Day for yazi

Holi Day is a light flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Holi family: The Indian festival of colours at full strength: gulabi-pink keywords, saffron strings, green types and blue methods, thrown like gulal over the ash of the Holika bonfire or over white cotton. Its colours are those of the Holi Day theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
light = "heritage-holi-day"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/holi) describes its colour tradition.
