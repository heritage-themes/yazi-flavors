# Wixárika Wirikuta (Light) for yazi

Wixárika Wirikuta (Light) is a light flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Wixárika family: The yarn paintings and beadwork of the Wixárika (Huichol): the five colours of maize, with yellow keywords, blue strings, purple fields, red types and peyote-green methods, on the black of the western sea or the light of the eastern desert. Its colours are those of the Wixárika Wirikuta (Light) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
light = "heritage-wixarika-wirikuta-light"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/wixarika) describes its colour tradition.
