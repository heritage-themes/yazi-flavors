# Tamil Kolam (Dark) for yazi

Tamil Kolam (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Tamil family: Tamil Nadu's kolam, palm-leaf manuscripts and Kanchipuram silk: peacock-neck keywords, mango strings, lac-red types and sapphire methods, on a dark granite threshold or a palm leaf. Its colours are those of the Tamil Kolam (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-tamil-kolam-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/tamil) describes its colour tradition.
