# Hmong Hemp (Light) for yazi

Hmong Hemp (Light) is a light flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Hmong family: The batik and cross-stitch of the Hmong pleated skirt: names in the tones of indigo batik, with pink keywords, lime strings and orange numbers from the cross-stitch, on indigo or undyed hemp. Its colours are those of the Hmong Hemp (Light) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
light = "heritage-hmong-hemp-light"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/hmong) describes its colour tradition.
