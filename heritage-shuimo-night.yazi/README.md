# Shuimo Night for yazi

Shuimo Night is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Shuimo family: Chinese ink-wash painting: hierarchy by ink tone and weight rather than hue, with indigo and ochre washes and a red seal as the only accents. Its colours are those of the Shuimo Night theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-shuimo-night"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/shuimo) describes its colour tradition.
