# Kalamkari Indigo (Dark) for yazi

Kalamkari Indigo (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Kalamkari family: Indian hand-painted textiles and their natural dyes, kept muted: aubergine keywords, indigo types, madder methods and myrobalan strings on a vat of indigo or unbleached cotton, outlined in iron-black ink. Its colours are those of the Kalamkari Indigo (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-kalamkari-indigo-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/kalamkari) describes its colour tradition.
