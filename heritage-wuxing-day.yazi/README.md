# Wuxing Day for yazi

Wuxing Day is a light flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Wuxing family: Chinese colour symbolism and the Five Elements: vermilion keywords (Fire), jade strings (Wood), imperial-yellow types (Earth), and a rice-paper or indigo-ink canvas in place of stark white and black (Metal and Water). Its colours are those of the Wuxing Day theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
light = "heritage-wuxing-day"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/wuxing) describes its colour tradition.
