# Edo Cha (Dark) for yazi

Edo Cha (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Edo family: The forty-eight browns and hundred greys of Edo-period dress: muted indigo keywords, brown literals, tinted-grey names, and a hidden red lining for the caret and labels. Its colours are those of the Edo Cha (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-edo-cha-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/edo) describes its colour tradition.
