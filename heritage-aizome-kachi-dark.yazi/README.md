# Aizome Kachi (Dark) for yazi

Aizome Kachi (Dark) is a dark flavor of [Heritage Themes](https://github.com/heritage-themes/heritage-themes) for [yazi](https://github.com/sxyazi/yazi), from the Aizome family: Japanese indigo dyeing in a single hue: hierarchy by depth of dye, with sashiko-white declarations, green-leaning asagi strings and violet-leaning kon numbers. Its colours are those of the Aizome Kachi (Dark) theme of the [Heritage Themes for terminals](https://github.com/heritage-themes/heritage-themes/releases/latest), which the terminal should run with it.

With this folder in yazi's `flavors` folder, name the flavor in yazi's `theme.toml`:

```toml
[flavor]
dark = "heritage-aizome-kachi-dark"
```

The [family's page](https://github.com/heritage-themes/heritage-themes/tree/master/themes/aizome) describes its colour tradition.
